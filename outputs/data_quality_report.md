## Decisions behind the numbers

- **Dedup rule:** prefer the helpdesk row over legacy_fd. Duplicate pairs differ by exactly
  5h30m in resolved_at — the legacy event-log UTC offset — so helpdesk rows carry IST times.
- **CSAT:** 0 and blank both mean no response (policy §8); never averaged as zero.
- **Refund units:** policy §9 warns legacy money is 'its own native unit'. Checked:
  legacy and helpdesk refund distributions agree (median 2374 vs 2499, same max), and no
  refund exceeds 3x retail. All amounts treated as rupees; no conversion applied.
- **Order fallback:** 720 blank-order tickets match multiple customer+SKU orders; 456 of the
  naive matches were newer than the ticket. Only orders dated on/before the ticket are used,
  latest first. 101 tickets have no prior order and stay blank.
- **transfers** exists only in the current helpdesk; transfer-cost math covers those rows only.
